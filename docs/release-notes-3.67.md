ボイスストーンの共有ローカル認識に対応する、PC版3.2.69との連携バージョンです。Web・Android・iOSのバージョンは3.67です。

- Web・モバイル参加者の音声認識は、PCホストが担当します。端末へ音声認識モデルを読み込んだり、音声認識APIのキーを登録したりする必要はありません。ホストはPC版の詳細設定から共有モデルを導入してください。
- タヌキ丼が未検出のときは、関連する録音・音量測定を停止します。未検出時の古い役職効果が残らない修正を維持しています。
- 3.66の個別音量スライダーの操作幅・中間値の保存に関する修正も含みます。

タヌキ丼β24とベタクルPC版3.2.69を推奨します。ブラウザの回帰テスト、lint、Web本番ビルドとパッケージの版番号を確認します。端末実機と多人数通話の検証は含みません。
