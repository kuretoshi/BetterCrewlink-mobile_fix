# NoSアドオンへのWeb・モバイル直接接続（ベータ機能）

本人のPCではNoSとアドオンを起動し、音声にはWeb/APKのベタクルを使います。本人のPC版ベタクルは不要です。声量とマイク状態は本人のWeb/APKから本人のアドオンへWSSで直接送ります。ホスト・ボイスサーバーによる役職通信の中継はしません。通常の通話とMobile Hostのゲーム情報配信は従来どおりです。

## 接続

1. NoSのロビーでビビリ・おしゃべり・メガホンレーザーのいずれかの役職設定を開き、マイクテスト欄の「Web・モバイル直接接続を開始／停止」を押します。割り当てられた役職は問いません。
2. 「直接接続先をコピー」で接続先をコピーします。`wss://PCのLANアドレス:57742/voice#接続キー` の形式です。同じPCのWeb版ならホスト部分を `127.0.0.1` に変更できます。
3. 初回はNoSが作成した公開証明書 `%LOCALAPPDATA%/TanukiBCL/NoS/direct-voice.cer` を使用するPC・スマホに手動でインストールして信頼設定します。秘密鍵 `direct-voice.pfx` はPC内に保持し、別端末へ移しません。証明書の自動インストールや検証の無効化はしません。
4. Web/APKを通常どおり本人の名前で部屋へ接続し、「NoSアドオンへマイクを直接接続」に接続先を貼り付けて「このマイクを役職に使う」を押します。
5. 両側に接続中と表示されたら、役職判定・マイクテストに使えます。

スマホは本人のPCと同じLANへ接続します。必要ならNoSのプライベートネットワークでのTCP 57742受信を許可してください。ゲストWi-Fiの端末間通信禁止・VPN・ファイアウォールで遮断される場合があります。インターネット経由の自動接続やポート開放は実装していません。

表示がVPN等の別アドレスなら実際のLANアドレスに変更してください。証明書には作成時のPCのIPv4アドレスとlocalhostを含みます。新しいIPへの変更・期限切れでは、待受を止めて証明書を再作成し、端末側でも再設定が必要です。証明書を勝手に交換しません。

## 証明書設定

- WindowsのWeb版：本人の公開証明書を現在のユーザーの信頼されたルート証明機関へ登録します。
- iPhone：証明書プロファイルをインストールした後、「設定 → 一般 → 情報 → 証明書信頼設定」で本人の証明書を信頼します。[Appleの手順](https://support.apple.com/en-us/102390)
- Android：本人の公開証明書をCA証明書としてインストールします。3.11の配布APKはシステム証明書と利用者が手動でインストールしたCA証明書を受け付けます。証明書検証は有効です。[Androidの仕様](https://developer.android.com/privacy-and-security/security-config)

接続先には本人専用のキーが含まれるため、他の参加者には共有しません。

## 判定と切断

本人のプレイヤーIDと接続キーを照合し、同時にマイク1つだけを受け付けます。サーバー発行の一回限りの短期チケット・連番で古い通信と再送を拒否します。声量は有限の0〜1に限定します。直接接続の開始中はPC版のUDP入力を使いません。

接続中のミュートは明示的なマイク停止として送ります。通信・ゲーム情報が途切れたら送信を止め、既存の未接続処理で判定を停止します。レーザーは追加蓄積を停止します。Web/APKの解除は役職通信だけを止め、通常のマイクを勝手にミュートしません。NoS側で停止するとキーが失効します。本人のプレイヤー変更・破棄でも停止します。Web/APKの部屋や本人IDが変わると接続を解除し、再入力を求めます。

ビビリ・おしゃべり・レーザー・マイクテストの共通入力処理へ追加しています。声の範囲・加工ON/OFF・死亡時の残響は既存の音声配信処理を使います。役職用の音声録音は保存しません。

## 検証

- アドオン：`dotnet run --project tests/GateTests.csproj`。実TLS/WSSでキー・本人ID・二重接続・ミュート・チケット期限・再送・再接続・不正声量と共通入力を確認します。
- Web/APK：`npm run test:nos-direct`。Web/APKの実クライアントからアドオンの実サーバー・共通入力まで接続します。PC版ベタクル・中継サーバーは使いません。
- ブラウザ：`npm test -- --configuration=ci`。接続・再接続・部屋変更・会議・ロビーテストを確認します。
- NoSの実コンパイラ、Webの本番ビルド、署名付きAndroidリリースビルドで検証しています。

テスト内だけはその場で生成した証明書を受け付けます。製品コードは証明書検証を無効化しません。iPhone Safari・Android実機での証明書・LAN権限・背景動作、ゲーム内UIと聞こえ方は未確認です。直接接続はベータ機能として配布しています。NoSアドオンのインストール・更新は別途必要です。
