# NoS役職のWeb・モバイル連携（ホスト中継・ベータ）

Web/APK → 既存のMobile Host（ホストのベタクル） → 同じPCのNoSアドオン → NoSのRPC → 本人の役職判定、という経路です。参加者本人のPC版ベタクル、証明書登録、LAN内の直接接続、追加の接続コードは不要です。

ホストのベタクルはPC版3.2.24以降、全員のタヌキ丼（TanukiBCL-NoSAddon）は0.8.0 Build37以降に更新してください。Web/APKは通常どおり本人の名前で参加すると声量・マイク状態を自動送信します。ホスト側のアドオンは自動でローカル受信を開始するため設定ボタンはありません。

Web・Mobile 3.15以降は、音声設定の「NoS役職のマイク感度」で役職に送る音量だけを調整できます。初期値100%、範囲25〜1000%。ビビリのメーターやメガホンレーザーの蓄積が弱い端末では、まず200〜300%に上げて同じ声で比較してください。通話音量は変わりません。大声での自滅判定やおしゃべりの発言判定にも影響します。ミュートは感度を上げても無言として扱います。

送信者のプレイヤーID・クライアントID・部屋を既存のシグナリング情報と照合し、再送と過剰な頻度を拒否します。ホストPC内の通信は127.0.0.1限定でプロセスIDと秘密トークンを照合し、古いサンプルと不正な値を破棄します。受信が止まると500msで声量が失効し、既存の役職側の未接続処理に移ります。音声そのものは追加送信しません。

Web/APKの表示「ホスト中継へ送信中」はホストのベタクルまでの受信確認です。NoSのRPC到達・役職への適用は実ゲームで別途確認してください。今回の検証はブラウザ単体191件、Web/APKクライアントからホスト検証・実UDP送信までの結合テスト、アドオンの受信値検証・役職入力のテスト、NoSコンパイルです。iPhone/Androidと複数NoSプロセスの実ゲームは未検証です。

旧3.11の直接接続方式は廃止しました。ホスト中継対応のWeb/APK・ベタクル・アドオンを一緒に使用してください。
