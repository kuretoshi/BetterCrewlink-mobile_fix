# タヌキのベタクルmobile 3.48

- UID BAN／IP BANに対応したサーバーによる利用資格確認を、Web・Android・iOSの共通経路で検証しました。接続元グローバルIPは本人のリクエストからサーバーが記録します。端末からIPを申告したり、観測した参加者へ本人のIPを割り当てたりしません。
- 履歴用の参加者名簿から本人を除外する判定を修正しました。PCホスト基準のフラグではなく、端末本人の接続IDを使用し、PCホストも履歴へ送ります。
- BANの登録・解除はPC版／.NET版の開発者画面で行います。モバイル版へ管理用パスワードや管理画面は追加していません。
- 音声検出の周波数解析バッファを再利用し、毎回のメモリ確保を減らしました。解析値・発話開始／終了・校正・音声の受け渡しは従来と同じです。
- PC版3.2.57／.NET版3.2.57-net-beta.1に互換バージョンを合わせました。

Web ZIPと署名済みAndroid APK／AABを配布します。iOS IPAは従来どおりサイドロード用の署名無しビルドです。AltStore Classic／SideStoreなどで再署名してください。

ブラウザ回帰テスト229件、VADのバッファ再利用・解析同値テスト、lint、型チェック、Web本番ビルド、Androidリリースビルド、iOS配布処理のテスト6件を実行しています。端末実機でのインストール・更新、NoS連携、同じ端末でAmong Usを前面に開いた間の通話継続は未検証です。
