PC版3.2.70の共有ローカル音声認識に対応するWeb・Android・iOS版3.68です。

- ヒーローの変身ワード・NGワード・ボイスストーンの音声認識はPCホストが担当します。ホスト側では共有モデル（Silero VAD＋SenseVoice）を使用できます。
- モバイル端末へのモデル導入や音声認識APIキーの登録は不要です。
- タヌキ丼が未検出のときに役職の録音・音量測定を停止する処理と、個別音量スライダーの修正を維持しています。

PCホストは通常版/Lite版3.2.70、Tauri版3.2.70-tauri-beta.1、.NET版3.2.70-net-beta.1へ更新してください。タヌキ丼β24に対応します。
