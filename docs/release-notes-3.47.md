# タヌキのベタクルmobile 3.47

- 接続設定に「画面レイアウト」を追加しました。「デフォルト」と「生存者・霊界を分ける」を切り替えられ、Web・Android・iOSで共通して利用できます。会議前の未公開の死亡情報は表示しません。

- 追加役職の録音用音声処理を、実際の録音中だけ接続するようにしました。
- PC版3.2.56／.NET版3.2.56-net-beta.1に互換バージョンを合わせました。

Web ZIP、Android APK／AAB、iOS IPAを配布します。iOS版は従来どおりサイドロード用です。
