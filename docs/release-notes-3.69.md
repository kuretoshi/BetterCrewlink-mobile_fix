PC版3.2.71と連携するWeb・Android・iOS版3.69です。

- SNRの衣装をPCホストが復元・着色したPNGで受信し、元の大きさと配置で表示します。
- 2個目の帽子（表・裏）とバイザーを、メインの衣装がない場合も表示します。
- 色連動する衣装はプレイヤーの色変更を反映し、固定色の衣装はそのまま表示します。
- 画像が一度読み込めなかった場合も、ホストから新しい画像を受信すると再表示します。

Mobile Hostを有効にするPCは通常版/Lite版3.2.71、Tauri版3.2.71-tauri-beta.1、.NET版3.2.71-net-beta.1へ更新してください。既存のNoS画像転送と音声処理も維持しています。
